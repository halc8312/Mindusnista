## 原作由来の計算とJava参照の比較

| 対象 | ケース数 | 判定 |
|---|---:|---|
| コンベア上の移動・間隔・横位置 | 120 | 位置の許容絶対誤差2e-6以内 |
| 向き・空き間隔・容量による受入可否 | 1,344 | booleanが完全一致 |
| 液体ブースト無しのドリル計算 | 40 | 進捗誤差0.002以内、warmup誤差2e-6以内、生産数一致 |
| 合計 | **1,504** | すべて成功 |

観測した最大絶対差は、コンベア位置で約 **6e-8**、ドリル進捗で約 **1e-4** でした。
Java floatとPythonの倍精度浮動小数点の差を許容しており、ビット単位一致ではありません。

**参照は原作のクラスから計算処理を切り出し、依存部分を外した独立したJavaプログラムです。**
原作エンジン全体を起動して結果を採取したものではありません。
更新順、隣接処理、全鉱石、効率や液体ブースト、MOD、原作通信の一致をこの比較から主張することはできません。
参照プログラムと生成済みデータを `reference/` に同梱しています。
