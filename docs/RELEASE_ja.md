# Pythonista 用の配布を作る

Python 3.10 以上の標準ライブラリだけで実行できます。Git・pip・ネット接続は不要です。
ゲーム本体の編集元は引き続き root の `mindustry_pythonista.py` 一つです。

```sh
python tools/check_project.py
python tools/build_release.py
python dist/mindustry_pythonista.py --self-test
```

既定の出力はプロジェクト直下の `dist/`。別の場所を指定する場合:

```sh
python tools/build_release.py --output dist/review-01
```

相対の `--output` はコマンドを実行した作業ディレクトリから解釈します。
指定なしの `dist/` は、作業ディレクトリにかかわらずスクリプトのプロジェクト直下です。

## 出力

| ファイル | 内容 |
|---|---|
| `mindustry_pythonista.py` | 編集元とバイト一致する iPhone 用ファイル |
| `Mindusnista-0.1.2-dev-source.zip` | ソース・テスト・参照・LICENSE/NOTICE・資料。最上位は `Mindusnista/` |
| `SHA256SUMS.txt` | 上記 `.py` と ZIP の SHA256。自身のハッシュは含めない |

版名はゲーム本体の `VERSION` 文字列を AST で読みます。本体を import・実行して版名を得ることはありません。
`build_release.py` 自体はゲームの正しさを検査しないので、上の検査コマンドも実行してください。
本体の版番号、ゲーム処理、保存 schema 1、起動ガード、操作は変更しません。

## 再現性と同梱範囲

配布対象は `tools/release_files.txt` に一件ずつ明記した相対パスだけです。
新しいソース・テスト・必要資料を追加したら、この一覧もレビューして更新します。
一覧にないファイルは拡張子にかかわらず読みません。`.git/`、`dist/`、キャッシュ、
ユーザーセーブ、ログ、個人設定、秘密鍵等の既知の私用パスは一覧に書いても拒否します。
任意の文書の内容から秘密情報を自動判定する機能ではなく、一覧と公開予定の内容を確認する必要があります。

ZIP は名前順、日時 1980-01-01 00:00:00、通常ファイル 0644、無圧縮で固定します。
ソースの更新時刻、実行場所、出力場所、ファイル権限は ZIP のハッシュに影響しません。
無圧縮なので zlib の差異にも依存しません。Git の情報や現在日時を埋め込みません。
展開したソース ZIP から、Git のない場所でも同じ三つの配布ファイルを再生成できます。

`HANDOFF_SHA256SUMS.txt` は最初の添付の履歴資料です。現在の配布を検査するものではありません。
新しい配布の照合には、その出力と同時に作った `SHA256SUMS.txt` を使います。

## 出力先を保護する動作

既存の出力ディレクトリは、三つのファイルが今回の生成結果と完全一致するときだけそのまま使います。
内容が違う、追加ファイルがある、空のディレクトリである等の場合は停止します。
既存のファイル・セーブを上書きしたり、ディレクトリを消去したりするオプションはありません。
変更後のソースをビルドするときは `--output dist/review-02` など未使用の場所を指定してください。

ソース内の出力先は `dist/` 以下に限定し、ソース直下・祖先・tests 等への出力は拒否します。
ソース、配布先、その親のシンボリックリンクも拒否します。入力検証・生成をメモリー内で終えた後、
未使用ディレクトリを確保し、各ファイルを新規作成専用で書きます。SHA256 一覧は最後に書きます。
書き込みエラー時は終了1とし、部分生成物が残ることがあります。既存データを消さず、再試行には新しい出力先を指定します。
三つすべてが完成して終了0になるまで配布しないでください。
ビルド中は同じ出力先の別操作やソース編集を避けてください。

## iPhone での確認

出力の `mindustry_pythonista.py` を Pythonista 本体のエディタで開きます。
旧スクリプトとセーブを退避し、保存フォルダーを削除せず [実機試験](../DEVICE_TESTS.md) の手順で確認します。
生成したファイルの PC self-test は、Pythonista / SpriteKit の実機動作を保証しません。
0.1.1 は起動成功のユーザー報告あり。0.1.2 の実機結果は引き続き未報告です。
