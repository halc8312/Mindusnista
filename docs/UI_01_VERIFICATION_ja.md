# UI-01 マス操作と誤スライド対策

2026-09-09。0.1.2-dev / 原作 v159.7 / 保存 schema 1 を維持。

## 依頼と基準

ユーザーの「マスもボタンで移動」「ボタン周りを細かくしすぎない」要望と、
連続設置の誤スライド報告を受けた。M1-01 の前に、この操作改善だけを実施する。
main `4a93f6b294e1656fa8710cda1126031cbe0da392` と open PR なし、作業ツリー clean を再確認。
この main から `ui/precise-placement` を作成した。古い添付は使っていない。

## 変更した操作

- 下部は従来の3段・16ボタンのまま。設備選択中だけウェーブ枠を「マス操作」ON/OFF に転用。
  ウェーブ開始はメニューにも追加した。
- 通常は従来の四方向・左右90度回転。マス操作 ON では同じ中央6枠を
  「↶・←・↑・↓・→・置く」に切り替える。色・ON表示・「1マス」の副ラベルで区別。
- 矢印は設置候補を1マスずつ動かす。大きい設備の寸法を含めてマップ端で止め、
  画面外へ動かすとカメラが追従する。既設設備や資源は変更しない。
- マス操作中は地面タップ・スライドも候補の移動だけ。「置く」で通常の費用・設置条件に従って確定。
  既設ベルトの明示的な向き変更は荷物・HP・ID・資源を保持。
- 通常のタップは開始マスに1回だけ操作。ズームを小さくした時の微小な指の揺れで別マスへ移らない。
- ベルト・銅の壁・撤去の連続操作は、画面座標7ポイント以内に0.35秒保持してから開始。
  準備ができると「連続設置OK」または「連続撤去OK」を表示。倍率によって閾値を変えない。
- 準備前のスライドはそのタッチ全体を取消。滑った後に待っても準備状態にならず、離した終点にも置かない。
  移動イベントなしで大きく離れた地点で指を離す場合も判定する。
- マス操作切替・マス移動・確定・ツール変更・メニュー・画面回転・停止・バックグラウンドで
  古い地図タッチを失効させる。ピンチや操作領域外への離脱も、以後の設置を止める。

長押し後の連続操作は従来どおり逐次確定する。後からピンチしても、すでに置いた・撤去した分は戻らない。
今回は誤スライドによる連続操作の開始防止であり、工場全体の undo や建築計画機能の追加ではない。
