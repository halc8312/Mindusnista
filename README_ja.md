## 向きとマスの操作

画面下部は、設備選択／方向・マス操作／移動・操作の3段、合計16ボタンです。
パネルの高さやボタン数を増やさず、設備を選んでいる間だけ下段の「ウェーブ」が「マス操作」に変わります。

| 状態 | 中央の6ボタン | 矢印の役割 |
|---|---|---|
| 通常（マス操作 OFF） | ↶・←・↑・↓・→・↷ | 設備の向きを選ぶ |
| マス操作 ON | ↶・←・↑・↓・→・置く | 設置候補を1マスずつ動かす |

### 新しく設置するベルト

通常モードで「ベルト」を選択し、中央の **←↑↓→** を押すと、その向きを直接選べます。
**↶** は反時計回り、**↷** は時計回りに90度ずつ回します。
選択中の方向ボタンが強調され、地面には半透明の設置プレビューと方向矢印が出ます。
プレビューだけでは建築しません。地面をタップし、指を離すと設置します。

地面に1本指を置いたまま、別の指で方向ボタンを押してから離す操作にも対応する設計です。
今回の変更の実機タッチは未検証です。

### ボタンで設置位置を調整する

設備を選び、下段の **「マス操作」** を ON にします。
中央の **←↑↓→** で半透明の設置候補を1マスずつ動かし、**「置く」** で確定します。
地面のタップやスライドでも候補を移動できます。このモードでは指を離しただけでは設置しません。
ベルトの向きは **↶** で90度ずつ変えられます。
「マス操作」を OFF にすると、従来の方向6ボタンとタップ設置に戻ります。
設備や操作ツールを選び直した場合も OFF に戻ります。

### 連続設置と誤スライド対策

通常モードのタップ設置はそのままです。連続操作は、地面で **0.35秒ほど指を動かさずに保持し、
準備完了の表示が出てからスライド** して始めます。対象はベルト・銅の壁・撤去です。
保持が完了する前に滑った場合、そのタッチでは設置・撤去しません。
細かい位置調整には、上の「マス操作」も使えます。

2本指のピンチに切り替えると以後の設置は止まりますが、長押し後のスライドですでに設置・撤去した分を
さかのぼって取り消す機能はありません。

### 設置済みベルト

「移動/調査」→ベルトをタップ→中央の方向ボタン、の順に操作します。
または「ベルト」で新しい方向を選び、既存のベルトを1回タップしても変更できます。
建て直しではないため、**資源消費なしで、同じ建物のID・HP・荷物を維持**します。
荷物のベルト上の相対座標は保ち、ベルトの向きと一緒に表示上の向きが変わります。

ドラッグで既存の工場を横切っただけでは、そのベルトを勝手に回しません。
連続設置は指定方向のままです。ドラッグの軌跡に合わせた自動方向・自動曲がりは未実装です。

### ベルト以外

今回の6種類の設備でプレイヤーが出力方向を指定するのはベルトです。
ドリル・分配器・壁はこの版では方向指定が不要、デュオの砲身は自動照準です。
そのため、これらを選ぶと通常モードの方向ボタンを薄く表示し、押しても設備を回転させません。
マス操作 ON では矢印による位置調整と「置く」が使えます。↶による回転はベルトだけです。
将来、方向を持つ設備を追加するときは対象を拡張します。

## 表示・速度・ゲーム操作

## 保存と起動修正の維持

原則はスクリプトと同じフォルダー内の `_mindustry_pythonista` に保存します。
書き込めない場合にPythonistaのDocuments配下を代替候補にする、0.1.1の仕組みを維持しています。
旧セーブを削除・自動移動しません。保存先が変わった場合は通知します。

手動保存は `manual.json`、自動保存は `autosave.json` です。
0.1.0 / 0.1.1と同じschema 1で、原作の .msav / .msch とは互換ではありません。
`_failed` / `_ready` による初期化ガードと、最初の例外をコンソール・可能ならcrash.logへ出す処理はそのまま残しています。

一部数値の変更には `content_overrides.example.json` を `content_overrides.json` として置き、編集して新規デモを開始します。

`python tools/build_single_file.py` で root の `mindustry_pythonista.py` を再生成し、
`python tools/check_project.py` で検査してください。root と src の両方を手編集して管理しません。
Pythonista で開く配布ファイルは従来どおり単体 `.py`。`src/mindusnista/app.py` は開発用です。
M0-03 の構造分割当時は、新設備・ゲーム処理・操作・版番号を変えず、生成物も分割前とバイト一致しました。

```sh
python tools/check_project.py
```

```sh
python -m unittest discover -s tests -v
python mindustry_pythonista.py --self-test
python mindustry_pythonista.py --benchmark
```

PC側はゲームロジックと模擬画面の検査です。Pythonistaの実機描画・操作・速度の検証とは別です。
